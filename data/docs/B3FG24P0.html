B3FG24P0Dépose - repose : Amplificateur de freinage
1. Dépose
Déposer :
  • La batterie
  • Le bac à batterie
  • Le calculateur (si nécessaire)
Figure : b3fp09cc
Désaccoupler le tube de dépression ( 1) de l’amplificateur de freinage.
Déposer vis (2).
Déposer les 2 écrous (3).
Dégager le support (4).
Déposer le maître-cylindre (voir opération correspondante).
Figure : b3fp09dd
Déposer :
  • L’axe (5) maintenu par une agrafe élastique
  • Les écrous (6)
  • L’amplificateur de freinage
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
NOTA : Utiliser une agrafe élastique neuve.
Serrer les écrous (6) à 2,3 m.daN.
