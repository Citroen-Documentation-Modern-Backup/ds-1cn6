B3FG1XP0Dépose - repose : Disque de frein avant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Remplacer systématiquement les plaquettes de frein lors du remplacement des disques.
1. Dépose
Déposer les plaquettes de frein  (voir opération correspondante).
1.1. Étrier BENDIX (disques non ventilés)
Figure : b3fp096c
Déposer les 2 vis (1).
1.2. Étrier LUCAS (disques ventilés)
Figure : b3fp097c
Déposer les 2 vis (2).
1.3. Étrier TEVES (disques ventilés)
Figure : b3fp098c
Déposer les 2 vis (3).
1.4. Dépose (suite)
Figure : b3fp099c
Déposer :
  • Déposer les 2 vis (4)
  • Le disque de frein (5)
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Couple de serrage :
  • Les 2 vis (1) (BENDIX) = 10,5 m.daN
  • Les 2 vis (2) (LUCAS) = 10,5 m.daN
  • Les 2 vis (3) (TEVES) = 10,5 m.daN
  • Les 2 vis (4) = 1 m.daN
