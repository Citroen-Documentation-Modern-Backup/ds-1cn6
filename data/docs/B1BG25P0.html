3. Dépose
Débrancher la borne négative de la batterie.
Lever et caler le véhicule, roues avant pendantes.
Vidanger :
  • La boîte de vitesses
  • Le circuit de refroidissement (voir opération correspondante)
Déposer :
  • Les roues avant
  • Les transmissions (voir opération correspondante)
  • La courroie d’entraînement d’accessoires (voir opération correspondante)
Désaccoupler :
  • La rotule d’échappement
  • Les biellettes de commande de boîte de vitesses À l’aide de l’outil [3]
Figure : b1bp1g4c
Déposer les vis (1).
Écarter le conduit haute pression ( 2) de direction assistée.
Figure : b1bp1jmc
Déconnecter le connecteur du compresseur de climatisation.
Désaccoupler la durit d’entrée de la pompe à eau.
Déclipper les durits d’arrivée et de retour carburant attenantes au moteur.
Déposer :
  • Les 4 vis (3)
  • Le compresseur de climatisation (suspendre le compresseur de climatisation à la caisse du véhicule)
  • La biellette anticouple (4)
Figure : b1bp1jnc
Déposer les agrafes (5), À l’aide d’un tournevis.
Écarter les équilibreurs.
Reposer les agrafes ( 5).
Figure : b1bp1jpc
Mettre le capot en position verticale , À l’aide de l’outil [2].
Figure : b1bp1jqd

  • Le calculateur d’injection (11)
  • Le bac à batterie
  • L’ensemble filtre à air (13)
  • Le couvercle (9)
  • La pompe de direction assistée (suspendre l’ensemble à la caisse du véhicule)
  • Le conduit de filtre à air (6)
  • Le support bac à batterie
Faire chuter la pression dans la rampe d’alimentation des injecteurs.
Désaccoupler :
  • Les durits d’arrivée et de retour carburant (10)
  • La durit de canister (7)
  • Le câble d’accélérateur
Déconnecter :
  • L’interrupteur à inertie (8) (couper le collier plastique de maintien)
  • L’électrovanne de purge canister (7)
Désaccoupler le câble d’accélérateur (13).

  • Le câble d’embrayage
Figure : b1bp1jsc
Mettre en place une grue d’atelier.
Élinguer le moteur À l’aide de l’outil [1].
Mettre en tension l’outil [ 1].
Protéger le faisceau du radiateur par un carton fort découpé aux dimensions du radiateur.
Déposer :
  • Le support moteur droit (22)
  • Le silentbloc gauche (23)
Faire descendre légèrement l’ensemble moteur-boîte de vitesses.

  • L’ensemble moteur-boîte de vitesses (incliner l’ensemble côté boîte de vitesses)
4. Repose
IMPERATIF : Remplacer systématiquement les écrous Nylstop.
Figure : b1bp1jtd
Remplacer les joints à lèvres de sortie de pont à l’aide des tampons [ 4a, 4b], après avoir garni de graisse l’intervalle entre les lèvres.
Enduire l’intérieur du support élastique de boîte de vitesses de graisse type " G7".
Présenter l’ensemble moteur-boîte de vitesses À l’aide d’une grue d’atelier.
Faire descendre légèrement l’ensemble moteur-boîte de vitesses.
Poser le support de silentbloc gauche ( 24).
Positionner l’ensemble moteur-boîte de vitesses.
Reposer :
  • Le silentbloc gauche (23)
  • Le support moteur droit (22)
Déposer l’outil [1].
Enlever la grue d’atelier.
Déposer le carton de protection.
Accoupler :
  • Le câble d’embrayage
  • Les durits encliquetables d’aérotherme (17)
  • La liaison d’assistance de freinage (18)
  • La durit (14)
  • Le câble d’accélérateur
  • La durit de canister (7)
  • Les durits d’arrivée et de retour carburant (10)
Connecter :
  • La sonde lambda (16)
  • Les faisceaux (20)
  • Le relais double d’injection (19)
  • L’électrovanne de purge canister (7)
  • L’interrupteur à inertie (8)
NOTA : Maintenir le connecteur de l’interrupteur à inertie avec un collier plastique.
